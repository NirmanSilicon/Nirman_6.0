1 · Where things stay the spatial decay curve · how likely each kind of object is still where you were told

How it is calculated. Every time Saarthi tells you where an object is, a clock starts. It stops when someone moves or takes that object (Saarthi's camera sees it), or is cut short (censored) when you are told again or the session ends. The Kaplan–Meier estimator turns these intervals into the chance the object is still there after t minutes; a constant-rate model, e−rate·t, summarises each kind. How Saarthi uses it. Ask "where is my cup?" about a cup seen long ago: once the curve for cups is below 50%, Saarthi says "…, but it may have been moved since" instead of stating an old place as fact.

2 · What goes together co-occurrence knowledge graph · which objects the camera sees in the same moment

How it is calculated. Once a second, the kit objects in view form a "basket"; each pair's lift (market-basket analysis) is how often they are seen together divided by how often they would be if unrelated: above 1 they belong together. Line thickness = seconds together; label = lift. How Saarthi would use it. Over a real week this learns a user's habits (the watch lives by the laptop), so a search starts where the object usually is. Honest limit: our recordings are one test table where everything is in view together, so the lifts are small; this shows the calculation, not a user's habits.
