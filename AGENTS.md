# Project identity

The project is named **Agent-X**. Use this name consistently in documentation and UI.
Use `agent-x` for deployment and artifact names, `agent_x` for Python identifiers,
and `AGENT_X_` for environment variables.

Use `docs/AGENT-X-FINAL-ARCHITECTURE.md` as the architecture reference and the two
briefs under `docs/briefs/` for the detailed product and sandbox requirements.
The final target architecture is reproduced in `README.md`. Keep the scaffold's
implemented features and remaining integrations accurately documented.
