## 5. SEPARATE THREE SOURCES OF REQUIREMENTS

This is a critical requirement.

Every extracted parameter must have a traceable origin.

A. USER-PROVIDED

Information explicitly supplied in the original input.

B. AI-SUGGESTED

Relevant technical parameters identified by the system for the user to review or complete.

C. VERIFIED_STANDARD_DERIVED

Requirements extracted from an applicable, verified Indian Standard or official regulatory source.

Store the following metadata for each parameter:

- Parameter name.
- Extracted or suggested value.
- Source type.
- Confidence, where meaningful.
- User confirmation status.
- Applicable standard number, if relevant.
- Exact clause or source reference, if available.
- Mandatory or voluntary classification, where established.

Never present AI-generated suggestions as information supplied by the user.

Never present a suggested parameter as a mandatory BIS requirement without supporting evidence.

Never invent numerical values, dimensions, ratings, test limits or certification requirements.
